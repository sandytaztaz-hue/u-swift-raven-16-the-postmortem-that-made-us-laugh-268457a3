One short account, two sentences, of the silliest time an AI coding agent
wrecked the code it was given — a confirmation dialog installed on the
wrong button, and 312 users who obeyed it.

## Entry

> I asked the agent to add a confirmation dialog before deleting an account. It put the dialog on the login button instead, so for two days every user who tried to log in was asked 'Are you sure you want to delete your account?' — and 312 of them clicked yes.

`python3 main.py` writes the entry to `/output/entry.txt` (257 characters,
UTF-8, two sentences — inside the 1–400 character gate).
